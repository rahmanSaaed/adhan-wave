# الأذان حول العالم 🕌

موقع تفاعلي بيوضّح إزاي الأذان بيتنقّل حوالين الأرض من غير ما يقف ولا ثانية.

الأرض بتلف، فوقت كل صلاة بيتنقّل من مدينة للي بعدها. الموقع بيرسم على كرة أرضية تفاعلية خط لكل صلاة، وبيوضّح المدن اللي فيها أذان في اللحظة دي.

## المميزات

- كرة أرضية ثلاثية الأبعاد تقدر تسحبها وتلفها، وفيها كمان عرض كخريطة مسطحة
- خمس خطوط ملوّنة بتوضح مكان الفجر والظهر والعصر والمغرب والعشاء دلوقتي، ومعاهم الليل والشفق
- عدّاد للمدن اللي فيها أذان دلوقتي، وقائمة "على الهوا" بآخر الأذانات والجاية
- زرار "يوم كامل في دقيقة" بيشغّل ٢٤ ساعة في ٦٠ ثانية
- تختار مدينتك وتشوف عدّاد تنازلي للأذان الجاي ومواقيت الصلوات
- ست لغات: العربية، English، Français، Türkçe، Bahasa Indonesia، اردو. الموقع بيختار لغة الجهاز تلقائيًا، وتقدر تغيّرها من القائمة أو من الرابط (مثلًا `#en`)
- شغّال على الموبايل

## التشغيل

```bash
npm install
npm run dev
```

ولبناء نسخة النشر:

```bash
npm run build   # الملفات بتطلع في مجلد dist/
```

مجلد `dist/` ملفات ثابتة، تقدر تنشرها على GitHub Pages أو Netlify أو Vercel أو أي استضافة.

## إزاي المواقيت بتتحسب

- مكان الشمس (الميل ومعادلة الزمن) بيتحسب بالمعادلات الفلكية المعروفة في `src/astro.js`.
- كل مدينة بتتحسب بالطريقة المعتمدة تقريبًا في بلدها: أم القرى، أو الهيئة المصرية، أو كراتشي، أو إسنا، أو رابطة العالم الإسلامي، أو غيرها.
- الخطوط على الكرة بتستخدم معايير رابطة العالم الإسلامي: الفجر ١٨°، والعشاء ١٧°، والعصر على المذهب الشافعي.
- المدن محطوطة كأمثلة (حوالي ٢٥٠ مدينة) في `src/cities.js`.

> المواقيت محسوبة فلكيًا، وممكن تختلف دقيقة أو اثنين عن التقويم الرسمي.

## هيكل المشروع

```
src/
  main.jsx     نقطة البداية
  App.jsx      الصفحة والواجهة
  Globe.jsx    رسم الكرة والخريطة (Canvas + d3-geo)
  astro.js     حسابات الشمس ومواقيت الصلاة
  cities.js    بيانات المدن
  land.js      تحميل حدود الدول
  i18n.js      الترجمات واللغات
  cityNames.js أسماء المدن بالحروف اللاتينية
  styles.css   التنسيقات
```

## إضافة لغة جديدة

ضيف اللغة في `LANGS` جوه `src/i18n.js`، وضيف قاموسها بنفس مفاتيح القواميس الموجودة.

## المصادر والشكر

- حدود الدول من خريطة العالم الخاصة بـ [Apache ECharts](https://echarts.apache.org) (رخصة Apache-2.0)، وبتتحمّل من jsDelivr وقت التشغيل.
- الفكرة مستوحاة من فيديو قناة [وشلون؟](https://www.youtube.com/watch?v=hqMDzHqbeAQ).
